FreePremium

Client Feature Guide — what the website does, how each part works, and why it exists

Adult video aggregation platform · Admin-managed · No public user accounts

This document is written for the business owner / client. It explains every major feature in plain language. Technical hosting notes are at the end.

1. What FreePremium is

FreePremium is a full website where visitors watch videos embedded from external hosts (YouTube, tube players, etc.). You manage all content from a private Admin panel. Visitors do not create accounts. Lists like Watch Later stay on their device.

Why: Fast to launch, low maintenance, no user-database / password resets for the public.

2. Public website (visitor side)

2.1 Age gate

What

Adults-only confirmation screen before entering the site.

How

Visitor clicks “I am 18 or older”. Choice is remembered in the browser. Search bots skip it so SEO still works.

Why

Legal / policy expectation for adult content sites.

2.2 Header navigation

  • Home — main page
  • Movies / Anime / Music — pinned category shortcuts
  • Pornstars — browse all performers
  • Categories ▾ — full category list (including Sports and adult niches)
  • Search — typeahead suggestions while typing
  • Random (🎲) — opens a random published video
  • Later — Watch Later list
  • Theme toggle — light/dark preference for the visitor

2.3 Homepage sections

  • Ad slot (top) — home banner ad area
  • Quick chips — fast filters (New, Most viewed, HD, Long, Exclusive)
  • Watch Later / Continue Watching — personal rows from the visitor’s browser
  • Popular tags — hot tags across the library
  • Featured — max 6 videos. If you feature a 7th, the oldest featured video is automatically removed from Featured
  • Trending now — horizontal rail of trending-marked videos
  • Latest uploads — newest 6 videos
  • More videos — older uploads move here when newer ones take Latest slots
  • Load more — infinite-style loading for more catalog items
  • Browse categories — category tiles toward the bottom

2.4 Categories

What: Niche pages like Amateur, MILF, POV, Hentai, Sports, etc.

How: Admin creates/edits categories (name, icon, image, order, on/off). Videos are assigned to a category.

Why: Helps visitors browse by taste and improves SEO landing pages.

2.5 Pornstars (performers)

What: Performer profiles with photo, bio, and all videos featuring them.

How: Admin → Performers to add name + image. Assign one or more performers on Add Video / CSV Maker. On the video page, visitors click a performer to open their page.

Why: Strong retention pattern on adult tube sites — people follow stars, not only titles.

2.6 Tags & search

  • Tags — comma-separated on each video; public tag pages list matching videos
  • Search — full search page + live suggestions in the header
  • Filters — sort, quality, exclusive, duration where available

2.7 Video watch page

  • Embed player — plays the external video URL
  • Exclusive unlock — gated videos need the site unlock code (set in Settings)
  • Sticky mini player — keeps playing while scrolling on supported layouts
  • Up next / related — suggested videos to keep binge watching
  • Autoplay next — optional countdown to the next related video
  • Views — site-managed counters (not copied from YouTube/tube host)
  • Performers row — clickable star chips under the title
  • Share buttons — copy link / social share helpers
  • Watch later — save to personal list
  • Report — visitor can report a problem video
  • Ad slots — header + sidebar placements

2.8 Watch Later & Continue Watching

Stored in the visitor’s browser (local storage). No login required.

Why: Zero friction. Limitation: lists do not sync across phones/computers.

2.9 Mobile bottom navigation

Quick links for Home, Hot, Later, Browse, Random — designed for one-thumb mobile use.

2.10 Legal / trust pages

  • Terms, Privacy, Content Policy
  • DMCA form (public) + admin inbox for requests
  • Video report form → Admin → Reports

Why: Required for responsible adult-site operation and dispute handling.

2.11 SEO tools (automatic)

  • Per-page titles/descriptions
  • /sitemap.xml and /sitemap-videos.xml for Google
  • Structured data (JSON-LD) on key pages
  • Google Search Console verification field in Settings

3. Advertising system

Slots: Home banner, video header, video sidebar, in-grid / mid-page, footer, native/in-feed, popunder (first click).

How: Paste ad-network HTML in Admin → Settings → Ad spaces. Empty slots stay hidden.

Ad preview mode: Toggle at the top of Settings. Turns on labeled demo ads so you can see exact placements. Saves instantly. Turn OFF before going live. Popunders do not fire while preview is on.

Why: Lets you test layout safely before pasting real adult-network codes.

4. Themes & look

Admin can pick skins (Neon Rose, Velvet, Chrome, Obsidian) or a fully Custom color set. Preview in admin, Save to apply site-wide.

Why: Brand control without hiring a designer for every color tweak.

5.1 CSV workflow (recommended for bulk)

  1. Admin → Performers / Categories — create what you need
  2. Admin → CSV Maker — fill each video, select performers, Add to list
  3. Create CSV / download
  4. Videos → Import CSV

CSV includes performerSlugs (comma-separated) and categorySlug.

5.2 Featured limit (important)

Featured holds only 6 videos. Featuring another video automatically unfeatures the oldest featured item. Works for single edit, bulk feature, and CSV import.

5.3 Exclusive videos

Mark a video Exclusive. Visitors must enter the Unlock Code from Settings before the player loads. Code is stored in settings — not hardcoded in the app.

6. Security & credentials (for the client)

Important: Admin username/password and session secret are not stored in the website source code. They live only in server environment variables (.env on the host). Never share them in chat/email screenshots.
  • Admin routes and APIs require a signed session cookie
  • Production refuses to start without strong SESSION_SECRET, ADMIN_PASSWORD, and site URL
  • Login, unlock, reports, DMCA, and view pings are rate-limited
  • Embed URLs are checked against an allowlist
  • Security headers (CSP-related protections) are applied

7. Hosting summary (zero / low budget)

FreePremium is a single Next.js app (frontend + backend together). Do not split Netlify frontend + Render backend.

  • Recommended free path: GitHub → Vercel (app) + Neon/Supabase (free Postgres) + Cloudflare (domain DNS)
  • Alternative free path: Oracle Always Free VM running the whole app + SQLite
  • Point your FreePremium domain via Cloudflare DNS to the host

Full technical steps: see project file DEPLOY.md

8. Go-live checklist

  • ☐ Set strong admin username/password + session secret on the host
  • ☐ Set public site URL to your real https domain
  • ☐ Turn Ad preview mode OFF
  • ☐ Set unlock code (if using Exclusive)
  • ☐ Paste real ad codes only from trusted networks
  • ☐ Submit /sitemap.xml in Google Search Console
  • ☐ Confirm age gate, one video page, one performer page, admin login
  • ☐ Backup the database after first content import
